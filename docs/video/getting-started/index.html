Başlarken: Sıfırdan Kurulum

Hiç gömülü yazılım derlememiş biri için hazırlandı. İlk seferinde 20-30 dakika sürer; ikinci seferde iki komutla biter.

Neye ihtiyacınız var
1 / 11
  • Desteklenen ESP32-S3 kartlarından biri gerekir.
  • Karta uygun uca sahip, veri aktaran bir USB kablosu gerekir.
  • Windows, macOS ya da Linux çalıştıran bir bilgisayar yeter; üçü de olur.
  • Şarj kablolarının bir kısmı veri taşımaz. Kart görünmüyorsa ilk deneyeceğiniz şey kabloyu değiştirmek olsun.
Bu adımların büyük kısmı bir kereye mahsus program kurulumudur. İkinci seferde iki komutla bitirirsiniz.
Telefon şarj kablolarının bir kısmı yalnızca elektrik taşır. Kart görünmüyorsa önce kabloyu değiştirin.
Terminali açın (macOS)
2 / 11
Bütün kurulum, yazıyla komut girilen bir pencereden yapılır. Bu pencerenin adı terminaldir.
macOS'ta ⌘ ve boşluk tuşlarıyla Spotlight'ı açın, Terminal yazın ve Enter'a basın.
Terminali açın (Windows / Linux)
3 / 11
Windows'ta Başlat menüsüne PowerShell yazıp Enter'a basın. Linux'ta Ctrl, Alt ve T tuşlarına birlikte basın.
Komutları tek tek yazıp Enter'a basacaksınız. Komut çalışırken bekleyin; bitince satır başı geri gelir.
Python kurulu mu, kontrol edin
4 / 11
Derleme aracı Python ile yazılmıştır. Terminale python3 --version yazın.
Python 3 ile başlayan bir sürüm görüyorsanız kuruludur. Görmüyorsanız python.org/downloads adresinden indirip kurun.
Windows'ta kurulum penceresinin altındaki "Add Python to PATH" kutusunu mutlaka işaretleyin.
PlatformIO'yu kurun
5 / 11
PlatformIO, kaynak kodu karta yüklenebilir dosyaya çeviren araçtır. pip3 install platformio komutuyla kurulur.
Kurulum birkaç dakika sürebilir. Bitince pio --version komutuyla doğrulayın; PlatformIO Core, version 6 gibi bir satır görmelisiniz.
pio: command not found hatası alırsanız programı tam yoluyla çağırın: macOS ve Linux'ta ~/.platformio/penv/bin/pio, Windows'ta %USERPROFILE%\.platformio\penv\Scripts\pio.exe.
USB sürücüsünü kurun
6 / 11
  • Karttaki USB çipi için bilgisayarın bir sürücüye ihtiyacı olabilir.
  • Çoğu bilgisayarda bu sürücü zaten vardır. Önce altıncı adımı deneyin.
  • Kart görünmüyorsa CH340 ya da CH341 ailesi sürücüsünü üreticinin sitesinden kurun.
  • Kurulumdan sonra bilgisayarı yeniden başlatın.
Çoğu bilgisayarda sürücü zaten vardır. Önce altıncı adımı deneyin; kart görünüyorsa bu adımı atlayın.
Görünmüyorsa CH340 ya da CH341 sürücüsünü kurup bilgisayarı yeniden başlatın.
Proje dosyalarını indirin
7 / 11
git clone komutu projeyi bilgisayarınıza kopyalar; cd NarRTOS-Wear komutu klasörün içine girer.
Bundan sonraki bütün komutları bu klasörün içindeyken çalıştıracaksınız.
git: command not found hatası alırsanız GitHub sayfasındaki Code menüsünden Download ZIP ile indirip klasöre girin.
Kartı bağlayın ve göründüğünü doğrulayın
8 / 11
Kartı USB kablosuyla takın; üzerindeki küçük ışık yanmalıdır. Ardından pio device list komutunu çalıştırın.
macOS'ta /dev/cu.usbserial, Linux'ta /dev/ttyUSB0, Windows'ta COM3 gibi bir satır kartın adresidir.
Hiçbir şey çıkmıyorsa sırayla başka bir USB kablosu, başka bir USB portu ve dördüncü adımdaki sürücüyü deneyin.
Derleyin ve karta yükleyin
9 / 11
Tek bir komut hem derler hem yükler: pio run -e esp32s3_wearable -t upload.
İlk derleme birkaç dakika sürer ve ekranda uzun satırlar akar; bu normaldir. Sonraki derlemeler 15 saniye kadar sürer.
Sonunda SUCCESS yazısını görürseniz işlem tamamlanmıştır; kart yeniden başlar. Yuvarlak ekranlı kart için ortam adı esp32s3_lcd128 olmalıdır.
Kodu değiştirdikten sonra önce -t clean ile temizleyin, sonra -t upload ile yükleyin.
Çalıştığını görün
10 / 11
Ekranda saat kadranı belirir. Sağa kaydırınca uygulama menüsü açılır.
Cihazın içeride ne yaptığını görmek için pio device monitor komutunu çalıştırın. Çıkmak için Ctrl ve C tuşlarına basın.
Monitör açıkken help yazıp Enter'a basarsanız cihazı komutlarla sürebilirsiniz.
İlk denemede en sık takılınan yerler
11 / 11
  • pio: command not found hatası, PlatformIO kurulu ama terminal onu bulamıyor demektir. Üçüncü adımdaki tam yolu kullanın.
  • pio device list boş dönüyorsa büyük ihtimalle şarj kablosu kullanıyorsunuz. Kabloyu değiştirin, sonra sürücüyü kurun.
  • Yüklemede checksum hatası alıyorsanız USB köprüsü yüksek hızda kararsız çalışıyor olabilir. Çözüm Sorun Giderme dökümanında.
  • Ekran açık ama görüntü yoksa yanlış kart ortamıyla derlenmiş olabilir. Yedinci adımdaki ortam adını kontrol edin.
Takıldığınız yer bu listede yoksa dokümandaki Sorun Giderme sayfasına bakın.
