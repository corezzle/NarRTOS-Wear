Hızlı Başlangıç

PlatformIO kuruluysa ve kart bağlıysa NarRTOS'u karta yüklemek için dört komut yeter.

Kod derlemeden yüklemek isteyenler
1 / 4
  • Corezzle Imager masaüstü uygulaması, NarRTOS'un hazır sürümünü karta sizin yerinize yazar.
  • Kartı takar, listeden kartınızı seçer ve düğmeye basarsınız. Kod derlenmez, hiçbir araç kurulmaz.
  • Adım adım anlatımı Corezzle Imager ile Yükleme dökümanında ve videosunda bulabilirsiniz.
  • Bu videodaki komutlar, kodu kendisi derleyip değiştirmek isteyen geliştiriciler içindir.
Amacınız yalnızca cihazı kullanmaksa Corezzle Imager yeter. Videonun geri kalanı geliştiriciler için.
Kuruluma başlamadan önce
2 / 4
  • Bilgisayarınızda VS Code yoksa önce onu kurun. Bunun için VS Code Kurulumu dökümanını izleyin.
  • VS Code kurulu ama projeyi içinde nasıl indirip açacağınızı bilmiyorsanız NarRTOS için VS Code Kurulumu dökümanına bakın.
  • İki döküman da ilk komutu nereye yapıştıracağınızı adım adım gösterir.
Aşağıdaki dört komut bir terminale yazılır. Terminali açmayı bilmiyorsanız önce bu dökümanlardan geçin.
Dört komut
3 / 4
İlk komut olan git clone, projeyi GitHub'dan bilgisayarınıza indirir.
İkinci komut olan cd NarRTOS-Wear, indirilen proje klasörünün içine girer.
Üçüncü komut olan pio run … -t upload, kodu derler ve karta yükler.
Son komut olan pio device monitor, cihazın seri çıktısını ekranda gösterir.
İlk kez mi kuruyorsunuz?
4 / 4
  • Bu dört komut, Python, PlatformIO ve git programlarının zaten kurulu olduğunu varsayar.
  • Bunları hiç kurmadıysanız Başlarken dökümanından ilerleyin.
  • Orada Python ve PlatformIO kurulumundan kabloyu takmaya kadar her adım tek tek anlatılıyor.
  • Yuvarlak ekranlı kart için komuttaki ortam adı esp32s3_lcd128 olmalıdır.
Ekranda pio: command not found görürseniz PlatformIO kurulu değildir ya da terminal onu bulamıyordur. Çözümü Başlarken dökümanının üçüncü adımında.
