NARRTOS WEAR

Karta yükleInstall to the board

Hiçbir program kurmadan, doğrudan tarayıcıdan. Kartı USB ile takın, kartınızı seçin, düğmeye basın; NarRTOS birkaç dakikada yüklenir. No software to install; straight from the browser. Plug the board in over USB, pick your board, press the button; NarRTOS is on it in a few minutes.

Bu tarayıcı USB'ye erişemiyor. Sayfayı Google Chrome veya Microsoft Edge ile açın (Safari ve Firefox desteklemez). Telefon ve tabletlerde çalışmaz; bilgisayar gerekir. This browser cannot reach USB. Open this page in Google Chrome or Microsoft Edge (Safari and Firefox do not support it). It does not work on phones or tablets; you need a computer.
1Kabloyu takınPlug in the cable

Kartı bilgisayara veri taşıyan bir USB kablosuyla bağlayın. Kartın ışığı yanmalı. Yalnız şarj kablolarıyla kart görünmez; en sık takılma noktası budur.

Connect the board to the computer with a USB cable that carries data. The board's light should come on. Charge-only cables make the board invisible; this is the most common snag.

2Kartınızı seçinPick your board

Aşağıda iki kart var. Ekranı dikdörtgen olan AMOLED, yuvarlak olan 240×240 LCD. Yanlış seçerseniz ekran karanlık kalır; tekrar doğrusunu yüklersiniz, zararı olmaz.

There are two boards below. The rectangular screen is the AMOLED, the round one is the 240×240 LCD. Pick the wrong one and the screen stays dark; just install the right one again, no harm done.

3Düğmeye basın, portu seçinPress the button, choose the port

Tarayıcı bir pencere açıp portları listeler. usbserial, wchusbserial veya COM ile başlayanı seçin. İlk kurulumda "Erase device" kutusunu işaretleyin.

The browser opens a window listing ports. Pick the one starting with usbserial, wchusbserial or COM. On a first install tick "Erase device".

Kart listede yoksaIf the board is not in the list Önce kabloyu değiştirin. Sonra USB sürücüsü: kartta CH343 çipi var; Windows ve macOS'ta sürücü gerekebilir (üreticinin CH34x VCP sürücüsü). Kurulumdan sonra bilgisayarı yeniden başlatıp sayfayı yenileyin. Change the cable first. Then the USB driver: the board has a CH343 chip; Windows and macOS may need the manufacturer's CH34x VCP driver. Restart the computer after installing and reload this page.
Bu sayfa ne yapıyor?What does this page do?

Tarayıcının Web Serial özelliğiyle karta seri porttan bağlanır ve Espressif'in açık kaynak esptool-js aracıyla yazılımı yazar. Yazılan dosyalar bu sunucudan iner; başka bir yere veri gönderilmez. Aynı işi bilgisayarında geliştirme ortamı kuran biri pio run -t upload ile yapar.

It connects to the board over the serial port using the browser's Web Serial feature and writes the firmware with Espressif's open-source esptool-js. The files come from this server; no data is sent anywhere else. Someone with a development setup does the same job with pio run -t upload.

  • Yükleme bittikten sonra kart kendini yeniden başlatır ve saat kadranı gelir.
  • When the install finishes the board restarts and the watch face appears.
  • Yükleme yarıda kesilirse kablo çekilmiş olabilir; tekrar takıp yeniden basın.
  • If the install stops halfway the cable may have been unplugged; plug it back in and press again.
  • Sürüm, bu sunucuda yayımlanan son sürümdür; daha sonraki güncellemeleri cihaz kendi indirir (OTA).
  • The version is the latest published on this server; later updates the device downloads itself (OTA).
